# 文献知识库实现路线

v0.2 · Codex 执行计划 · 2026 年 11 月 16 日

执行依据为[需求分析](literature-knowledge-base-requirements.md)和[整体架构](literature-knowledge-base-architecture.md)。完成条件是我能在当前项目中实际跑通**导入两篇 PDF → 按问题判断是否查库 → 对比两篇并在必要时补查 → 点击引用高亮原页 → 保持预览继续追问**，并能复现异常路径。

每步按「检查现状 → 实现最小闭环 → 运行验证 → 修复可恢复的问题」推进。进入下一步前记录相关文件、运行过的验证和仍存在的限制。以个人本地使用和带文字层的 PDF 为首版范围。

## 0 确认可运行的基线

- 检查 Git 工作区和待提交差异，从当前的证据筛选、通用回答回退和右侧预览继续实现。
- 检查本地依赖与服务，运行前端构建，复测流式问答及打开预览后继续提问。使用独立临时数据目录做会写入、迁移或删除文件的验证。
- 准备小批可核对的 PDF 样本和问题，包含中英文、双栏、旋转或裁切，以及同主题但缺少答案的检索样例。记下已知页码和原文。

**通过条件** · 现有服务和核心交互可复现，样本有可核对的预期结果。若环境失败，先诊断并完成可恢复的修复。

## 1 实现 PDF 引用与原页高亮（FR-06）

- 先确定版本 ID、片段 ID、PDF 页序、页内矩形和证据摘录的接口形状。
- 在后台解析侧用 pdfplumber 从真实 PDF 提取带坐标的已知片段。用这个片段构造一条测试引用，提供按版本读取原件的入口。
- 在现有右侧栏用 PDF.js 加载该版本，跳到证据页并按坐标高亮。先完成单篇纵向闭环，再补跨页、双栏、旋转和裁切的样本验证。
- 在浏览器中调整缩放、切换引用，并保持右栏打开继续发送。用无法定位的片段验证摘录和状态提示。

**通过条件** · 能从已知证据跳到真实 PDF 原页，高亮与原文对应，缩放后仍准确。坐标契约可复用到入库和问答阶段。

## 2 接通真实入库、索引发布和旧库迁移（FR-01、FR-02）

- 从步骤 1 的版本与坐标契约扩展 SQLite 文献、版本、片段、专题和任务记录。接通上传、去重、状态查询、后台解析与重试。
- 将正文及坐标写入新索引代次，分别构建全文与向量索引，全部就绪后切换可检索代次。
- 先在临时副本验证从现有 JSON 元数据迁移，再让正常应用路径兼容旧数据。用重复导入、故障注入和服务重启验证可重试及索引一致性。

**通过条件** · 可在页面导入、查状态及重试，正常文件可查，损坏和需 OCR 的文件有明确提示。新索引准备期间旧索引可查，旧原件和已发布引用可核对。

## 3 替换问答的检索层并提供只读工具（FR-02、FR-04）

- 将 FTS5 与 Chroma 的召回限制在相同的用户选择范围和活动索引代次。用 RRF 合并候选，保留论文名、缩写和 DOI 的精确入口。
- 提供文献列表、候选检索、原文与相邻片段读取三个接口。用证据 ID 登记实际读回的片段和定位信息。
- 在同一题集上对比现有向量和混合检索，分别检查精确术语、改写问题、跨专题误命中和无证据。定位排序或切分问题后再调整。

**通过条件** · 两条召回路径都遵守范围和版本约束，读回的证据与准备好的 PDF 页码相符，能复现并对照向量与混合检索的结果。

## 4 接入自动路由、Agent 补查和会话（FR-03 至 FR-07）

- 在现有聊天流接口后接入「自动」「仅查文献」「通用回答」。先用可控响应验证每条分支，再用已配置的 DeepSeek 做少量端到端验证。
- 用 LangGraph 接通只读工具、证据覆盖判断和一轮定向补查。区分通用回答、查库无证据和服务错误，校验完成事件中的引用。
- 保存会话、明确的查询范围、比较对象和引用。用「第二篇的局限是什么」确认指代解析后会重新查证。把生成的真实引用接到步骤 1 的 PDF 右栏。

**通过条件** · 通用题直答，明确查库的问题会查库，跨篇问题缺一侧会补查，库内证据不足时按模式处理。点击真实引用可以在原页高亮，追问命中正确文献，新会话的范围独立。

## 5 从干净环境复验并同步交付

- 运行前端构建和针对性测试，在独立数据目录复现整个演示。覆盖通用问答、单篇定位、跨篇比较、连续追问和无证据，记录证据命中、引用页码和响应耗时。
- 复测解析失败、模型超时、索引切换、重启恢复、流式中断和预览时继续提问。按正常启动方式检查可复现性。
- 核对 FR-01 至 FR-07 与 NFR-01 至 NFR-04。实际行为或验收改变时同步修改需求文档；模块、接口、数据契约或部署改变时同步修改架构文档。按当前授权处理提交和推送。

**完成条件** · 能报告实际跑通的操作、测试结果和仍未验证的限制，开发结果与需求和架构文档一致。
