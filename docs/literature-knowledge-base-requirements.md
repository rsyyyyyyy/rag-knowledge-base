# 文献知识库需求分析

v0.1 · 评审草案 · 2026 年 11 月 16 日

## 1 产品目标与范围

面向需要阅读、比较和整理文献的学生及研究者，提供以 PDF 为主的个人文献库。用户可以在同一处查资料、阅读原文、向大模型提问，并回到论文原页核对结论。资料可覆盖多个学科，通过专题、标签和书目信息组织。

**核心用例**是比较两篇论文的方法和评估数据。用户选定文献后提问，系统分别取证并针对缺失项补查。用户在右侧打开证据页，接着追问第二篇论文的局限。

**首版范围**包括可选中文字的 PDF、专题管理、三种问答模式、单篇与跨篇问答、连续追问及 PDF 原页高亮。现有项目已经可以导入文件、检索片段、流式回答和在右侧高亮提取文本。自动判断是否查库、文献版本管理和 PDF 原版式高亮属于本版需求。

## 2 首版功能需求

### FR-01 导入文献并查看入库状态

支持批量导入带文字层的 PDF，保存原文件并展示待处理、处理中、可检索和失败状态。用户可查看失败原因并重新处理。扫描件应明确提示需要 OCR。

**验收** · 同时上传正常 PDF 和损坏文件，正常文件可以被检索，损坏文件显示可理解的错误。重复上传相同文件时提示已存在。

### FR-02 按书目信息组织跨学科文献

显示标题、作者、年份和可取得的 DOI 或来源。用户可以修正识别错误，添加专题和标签，按标题、作者、年份或专题查找文献。同一作品的预印本和正式版可以区分。

**验收** · 导入两个领域的文献后，用户可筛选其中一个专题，并将提问范围限定到所选专题或指定文献。

### FR-03 选择和识别问答模式

提供自动、仅查文献、通用回答三种模式。自动模式判断问题是否需要库内证据，并识别明确的文献、专题和当前阅读对象。有歧义且会影响答案时先追问。用户手动选择的模式和范围优先。

**验收** · 在自动模式下，「什么是召回率？」直接答，「库里哪些论文报告了召回率？」查库。显式选择通用回答时，本轮不查库。明确锁定一篇文献时，回答的库内引用只出自该篇。

### FR-04 按证据回答、比较和补查

阅读块保留段落、章节及可识别表格上下文，引用证据定位到支持具体论断的原句。每条引用在输出完成前核对原文引句、版本和数值，必要时在同一文献内补读；无法支持时说明依据不足，不生成错误的原文链接。正文引用使用紧凑编号，同一证据合并；词级定位不可用时按行或页降级。已有文献自动升级索引，期间可用旧索引，旧会话引用继续打开原版本。

介绍、总结或整体比较指定文献时覆盖全部已解析正文，不以少量检索命中替代全文阅读。短文直接阅读；长文按预算逐批阅读并汇总，回答直接呈现结论与正文引用，不展示片段数量、分批汇总提示及内部分析过程；资料未解析造成证据不足时说明可核验范围。具体主题检索保留局部取证，并补充命中片段上下文。正文中的引用可点击定位；末尾仅保留按文件聚合的原文入口，不再重复列出引用片段编号和数量。历史会话也遵循此展示规则，原始记录保留。全文阅读后的引用仍定位原文版本、页码和片段，不能将中间摘要伪装为原文。

支持单篇阅读问答和多篇文献比较。复杂问题按对象和比较维度取证。证据只覆盖一侧时，可针对另一侧补查。在引用实验结果时保留数据集、样本、基线、指标等适用条件，并指出证据缺口或不同口径。

**验收** · 比较两篇论文的实验结果时，能分别定位两篇的结论与实验条件。只命中一篇时有定向补查记录。补查后仍缺失的一侧明确标注待确认。

### FR-05 证据不足时继续提供适当帮助

自动模式可以在库内证据不足时继续流式给出通用解释，并显式区分回答依据。仅查文献模式应展示可确认的部分和缺少的依据。可在答案完成后打开本轮引用的原文。

**验收** · 对和库内文献无关的概念提问，自动模式输出通用解释且来源区为空。将同一问题切换到仅查文献模式，结果说明本轮未找到支持证据。

### FR-06 从结论跳转到 PDF 原页

答案中的可核查结论带引用编号，来源按文献合并。点击编号，在问答页右侧打开对应版本的 PDF 并高亮证据。同一文献的多处证据可逐一定位。右栏支持连续滚动查看 PDF 全部页面，并通过命中页按钮快速跳转。鼠标位于 PDF 上时，按住 Ctrl 滚轮缩放；并排布局可拖动问答区和预览区之间的分隔线。右栏开启时仍可在左侧发送问题。

**验收** · 点击两条引用能分别跳到实际 PDF 页，并高亮对应段落。新提问不会关闭当前预览。无法定位的引用显示原因和可查看的原始片段。

### FR-07 在同一会话中延续文献追问

保存会话消息、用户已明确的文献范围与上一轮引用。刷新后恢复最近使用的会话，左侧可打开历史对话或新建独立会话，并可重命名（去除首尾空白后1至100字符）或确认删除单个会话。删除清除该会话的消息、范围、引用及记忆索引；删除当前会话后进入空白新会话，知识库文献保留。智能问答的附件按钮提供悬浮提示，选择加入知识库后，能提取文字的文件也会随下一条消息发送，无需等待索引。能识别「这篇」「第二篇」「另外两篇」等指代，维护用户当前讨论对象与完整文献清单，并在需要时重新查证。用户只发送文件名时，确认选中文献并询问概览、深读或比较任务。

**验收** · 比较两篇文献后追问「第二篇的局限是什么？」能够指向正确文献。列出三篇后选中一篇，追问「另外两篇」正确排除当前文献。找不到某篇后，下一轮仍能查询其他实际存在的文献。新建会话时，旧会话中的文献选择和指代不会进入新会话。

### FR-08 章节与原文证据的结构关系

已实现章节、父子关系、正文顺序和页区间的持久化。阅读页提供“章节原文”，可读取所选章节及其子章节，点击文段定位 PDF 原页并高亮。正文分页读取，同一章节加载后续内容时继续检查版本与索引代次。

旧库在启动时从已解析片段补齐关系。补齐过程保留原件、正文、片段 ID、元素与坐标，重建时在同一事务中发布新章节关系。章节标题沿用现有解析器的识别结果，复杂版式及图内文字仍可能影响标题准确性。

验收覆盖父子章节范围、分页完整性、旧库重复迁移、发布失败回滚、范围过滤、过期版本拒绝及原页高亮。

章节摘要和论文卡片已接入阅读页“文献卡片”。后台分批阅读当前版本全部已解析正文，提炼章节要点，并选择研究问题、方法、发现、适用条件与局限。每项要点关联逐字原句、版本、页码与高亮位置。模型先生成候选要点，应用校验原句位置和显式数值，再由模型复核归纳是否受引句支持及字段分类；卡片整理只能选择已有要点，不能新造事实。无法确认的字段留空，部分失败明确提示，不展示内部分析或正文片段数量。

新文献索引发布后自动排队，已有文献可手动生成、重试或重新生成。同版本和配置复用缓存，失败重试及服务重启可从已完成批次恢复。替换文献或变更模型、Prompt、解析配置后不复用旧卡片。重新生成失败时保留原有效结果。验收覆盖缓存、重试、过期任务拒绝、原句核验及点击 PDF 高亮。模型语义复核仍需人工抽查；本项不包含论文卡片召回与专题报告。

## 3 质量要求

- **NFR-01 可追溯性**。引用关联到确定的文献版本与 PDF 页码。重建索引后，无法复现的旧引用有清晰提示。
- **NFR-02 响应体验**。答案流式呈现。解析、检索、补查等等待环节有状态反馈。预览和问答区独立滚动。
- **NFR-03 故障恢复**。单篇解析失败可以独立重试。模型服务错误、解析错误和没有证据分别显示。
- **NFR-04 数据边界**。文献保存在本地工作区。通用回答模式不发送库内片段，文献模式只向配置的模型提供回答所需的片段。

## 4 验收范围

用包含不同主题和语言的代表性 PDF，人工标注期望的问答模式、事实结论和原文页码。评测覆盖以下场景：

- 通用概念题与明确查库题。核对自动模式是否走到预期路径。
- 全文覆盖：在正文末尾放置关键事实，核对短文直接读取和长文逐批阅读均纳入该事实；核对超过八篇的概览没有静默截断，并验证中间汇总引用不越界。
- 结构与引用：核对双栏阅读顺序、段落合并、长段落末尾、表头保留、旋转页坐标；伪造引句、错误数值、错误版本不能产生可点击引用，缺失证据可定向补读。
- 单篇定位与跨篇比较。核对必要原文是否命中，结论引用是否指到正确文献、版本及页码。
- 不完整证据与无证据。核对是否补查缺失项，回退回答是否正确标注依据。
- 会话内连续追问与新会话。核对指代是否正确，切换会话后是否清除旧范围。
- 并排阅读与继续提问。核对右侧 PDF 高亮、左侧发送及两栏独立滚动。

记录检索命中情况、原文对结论的支持情况、引用定位成功率和响应耗时。性能目标在测出基线后确定。
